ALGORITMO DE IMPACTO BRUSCO Y CONFIRMACIÓN DE CAÍDA (FASE 2) — CENTINELA v2.0

1. FUNDAMENTO FÍSICO:
   - Al terminar una caída libre y chocar el bastón o el usuario contra la vereda,
     se produce una desaceleración cinética abrupta que genera un pico que excede
     ampliamente la gravedad terrestre normal.

2. CRITERIO Y CONDICIÓN DE FASE 2 (MOVIMIENTO.CPP):
   - Constante: MPU_UMBRAL_GOLPE = 1.75f (G).
   - Constante: CAIDA_VENTANA_MS = 800 milisegundos.

3. MÁQUINA DE ESTADOS Y CORRELACIÓN TEMPORAL:
   - Si _accelTotal > 1.75G:
     * Caso A (¡Caída Real Confirmada!):
       Si _enCaidaLibre == true y (millis() - _tsCaidaLibre) < CAIDA_VENTANA_MS:
         _eventoActual = EventoMovimiento::CAIDA_TOTAL;
         Estado::setCaidaConfirmada(true);
         _enCaidaLibre = false;
     * Caso B (Golpe aislado / Toque de bastón en el piso):
       Si _enCaidaLibre == false:
         Se clasifica como EventoMovimiento::IMPACTO simple.
         NO dispara alarma de emergencia, permitiendo que el usuario ciego camine
         tocando el suelo con el bastón sin interrupciones ni falsas alarmas.
