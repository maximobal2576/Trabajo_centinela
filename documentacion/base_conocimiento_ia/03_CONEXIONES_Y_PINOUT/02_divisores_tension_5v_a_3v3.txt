===============================================================================
DIVISORES DE TENSIÓN: PROTECCIÓN DE ENTRADAS DIGITALES (5V A 3.3V)
===============================================================================
1. PROBLEMA ELÉCTRICO:
   - Los tres sensores ultrasónicos HC-SR04 se alimentan con 5.0V y sus salidas ECHO
     generan pulsos lógicos a nivel de 5.0V.
   - El microcontrolador ESP32 opera a 3.3V y sus entradas no son tolerantes a 5V.
     Aplicar 5.0V de forma continua puede degradar o quemar permanentemente los
     diodos internos de protección y el silicio del chip.

2. ESQUEMA DEL DIVISOR RESISTIVO (1 kΩ / 2 kΩ):
   
   ECHO HC-SR04 (5.0V) ───── [ R1 = 1 kΩ ] ─────┬───── GPIO ESP32 (3.33V)
                                                │
                                          [ R2 = 2 kΩ ]
                                                │
                                               GND

3. CÁLCULO MATEMÁTICO:
   Vout = Vin * ( R2 / (R1 + R2) )
   Vout = 5.0V * ( 2000Ω / (1000Ω + 2000Ω) )
   Vout = 5.0V * ( 2 / 3 ) = 3.333 V.

4. APLICACIÓN EN CENTINELA v2.0 DEFINITIVO:
   - ECHO Frontal: Pin ECHO del HC-SR04 Frontal -> Divisor 1k/2k -> GPIO 34 del ESP32.
   - ECHO Suelo:   Pin ECHO del HC-SR04 Suelo   -> Divisor 1k/2k -> GPIO 35 del ESP32.
   - ECHO Radar:   Pin ECHO del HC-SR04 Radar   -> Divisor 1k/2k -> GPIO 36 del ESP32.
===============================================================================
