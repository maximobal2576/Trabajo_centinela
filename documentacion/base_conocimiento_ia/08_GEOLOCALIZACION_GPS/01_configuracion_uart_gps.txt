CONFIGURACIÓN DE PUERTO SERIE PARA GPS NEO-6M (GPS.CPP) — CENTINELA v2.0
===============================================================================
1. PUERTO HARDWARE SERIAL2:
   - El microcontrolador ESP32 posee 3 controladores UART por hardware independientes.
   - Serial0 (Pines 1 y 3) está asignado a la consola de programación y diagnóstico USB.
   - Serial2 se asigna exclusivamente al receptor GPS NEO-6M:
     * GPIO 16 (GPS_RX_PIN): Conectado a la línea TX del módulo GPS.
     * GPIO 17 (GPS_TX_PIN): Conectado a la línea RX del módulo GPS (opcional).
   - Velocidad de baudios: 9600 baudios (8N1).

2. INICIALIZACIÓN EN GPS.CPP:
   void GPS::iniciar() {
       Serial2.begin(GPS_BAUDRATE, SERIAL_8N1, GPS_RX_PIN, GPS_TX_PIN);
       _nmeaBuffer.reserve(128);
       _latitud        = 0.0f;
       _longitud       = 0.0f;
       _gpsFix         = false;
   }

3. MECANISMO DE RETENCIÓN DE COORDENADAS (RESOLUCIÓN DE TÚNELES / TECHOS):
   - Problema real en la vía pública:
     Al ingresar a una estación subterránea, túnel, negocio techado o bajo marquesinas densas,
     el módulo GPS pierde visibilidad satelital (Fix = false). Si las variables se resetearan
     a (0.0, 0.0), el sistema perdería la ubicación del usuario ante una emergencia.
   - Solución implementada en Centinela v2.0:
     Cuando _gpsFix pasa a false, las últimas coordenadas válidas registradas se preservan
     intactas en memoria RAM. Ante una activación de SOS o Caída, la telemetría despacha
     estas últimas coordenadas certeras, permitiendo que los servicios de auxilio sepan
     con exactitud dónde se encontraba el usuario instantes antes de perder satélites.
