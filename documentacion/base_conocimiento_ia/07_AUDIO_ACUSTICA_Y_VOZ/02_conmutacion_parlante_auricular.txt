1. CONDICIÓN DE AURICULARES (AUDIO.CPP):
   bool Audio::auricularesConectados() {
       return (digitalRead(PIN_JACK_DETECT) == NIVEL_JACK_CONECTADO); // GPIO 14 == LOW
   }

2. CONTROL DEL PIN DE SHUTDOWN (I2S_SD_PIN = GPIO 32):
   void Audio::habilitarAmplificador(bool on) {
       // Si hay auriculares conectados, el amplificador exterior NUNCA se enciende:
       if (on && Estado::getAuricularesConectados()) {
           digitalWrite(I2S_SD_PIN, LOW);
           return;
       }
       digitalWrite(I2S_SD_PIN, on ? HIGH : LOW);
   }

3. COMPORTAMIENTO RESULTANTE Y PRIVACIDAD:
   - Con auriculares desconectados (GPIO 14 == HIGH):
     * El amplificador MAX98357A se habilita cuando hay audio activo (GPIO 32 = HIGH).
     * Las indicaciones de navegación y alertas se emiten por el altavoz de 3.2W.
   - Con auriculares conectados (GPIO 14 == LOW):
     * El pin SD se fuerza a LOW inmediatamente, apagando el altavoz público.
     * La señal analógica viaja únicamente a los auriculares para total discreción.
   - Sin audio reproduciéndose:
     * El pin SD se mantiene en LOW para apagar el amplificador (< 0.6 µA de consumo),
       suprimiendo todo siseo estático y maximizando la autonomía de la batería.
